Challenge

The Problem

Manual builds and deployments are slow and easy to get wrong. Without automated checks, a broken change can reach production unnoticed.

Goal: ship every change through the same repeatable, automated path.

Solution

The Approach

A simple game with two-player turns, real-time win detection, and a restart option keeps the app small, so the focus stays on the pipeline: GitHub Actions validates each commit, then Vercel deploys it.

Outcome: push to GitHub, and the new version goes live automatically.

How the Pipeline Works

01 / SourceCode CommitChanges are pushed to the GitHub repository.
02 / TriggerGitHub ActionsThe workflow starts on push or pull request.
03 / ValidateBuild & CheckDependencies install, the build runs, and checks must pass.
04 / DeployVercelA successful build is deployed to the live site.
